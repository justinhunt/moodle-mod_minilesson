MiniLesson Module for Moodle
=============

Poodll MiniLesson is a self-guided, auto-graded language practice activity for Moodle. A lesson is
a sequence of items (multiple choice, dictation, gap fills, read aloud, listen and repeat, free
speaking/writing with AI feedback, AI audio chat, vocabulary games and more), graded automatically
using speech recognition and AI.

MiniLesson requires a Cloud Poodll API username and secret from https://poodll.com
See here: https://support.poodll.com/support/solutions/articles/19000083076-cloud-poodll-api-secret

See README.md in this folder for the full documentation: features, installation, site settings,
the complete list of item types, AI lesson generation and developer notes.
